## 仓库地址

https://github.com/Danmaku-Anywhere/danmaku-anywhere

## 开发环境

- `Node.js` 版本以扩展仓库的 `mise.toml` 为准。
- `pnpm` 版本以扩展仓库 `package.json` 中的 `packageManager` 字段为准。请使用 `pnpm`，不要使用 `npm` 或 `yarn`。
- Chrome（开发浏览器扩展时由 `dev:browser` 自动启动）

## 项目结构

本项目为`pnpm`多包`workspace`。

<FileTree>

- packages/
  - **danmaku-anywhere/** - 扩展主体
    - src/
      - background/ - 后台脚本（Service Worker）
      - content/ - 内容脚本
        - controller/ - 控件
        - player/ - 弹幕播放器
      - popup/ - 弹出窗口
    - e2e/ - Playwright e2e 测试与开发浏览器启动脚本
  - danmaku-model/ - 共享数据模型（弹幕、剧集、季度等）与 XML 转换，扩展与 Web 应用共用
  - extension-protocol/ - 扩展与 Web 应用之间的消息格式
  - danmaku-engine/ - 弹幕渲染器
  - danmaku-provider/ - 与第三方弹幕源 API 交互，仅供扩展使用
  - web-scraper/ - 网页/媒体元数据抓取，仅供扩展使用
  - integration-policy/ - 站点集成策略 schema
- package.json

</FileTree>

## 安装

<Steps>

1. 安装依赖
   ```bash
   pnpm install
   ```
2. 在扩展仓库根目录构建共享包
   ```bash
   pnpm build:packages
   ```
</Steps>

## 开发

### 浏览器扩展

扩展位于 `packages/danmaku-anywhere`。

<Tabs>
  <TabItem label="Chrome">

    推荐使用 `dev:browser`，会自动启动一个独立的 Chrome 实例，并加载扩展：

    ```bash
    pnpm dev:browser
    ```

    支持HMR，改动源码会自动刷新。用户配置保存在 `packages/danmaku-anywhere/.playwright-profile`，可重复使用。

  </TabItem>
  <TabItem label="Firefox">
    Firefox开发需要`web-ext`，每次改动后需要重新构建

    用`--watch`选项运行构建命令
    ```bash
    pnpm build:firefox --watch
    ```

    另开一个终端运行
    ```bash
    pnpm start:firefox
    ```

  </TabItem>
</Tabs>

#### 构建

<Tabs>
  <TabItem label="Chrome">

    ```bash
    pnpm package
    ```

  </TabItem>
  <TabItem label="Firefox">

    ```bash
    pnpm package:firefox
    ```

  </TabItem>
</Tabs>

输出在 `packages/danmaku-anywhere/package`。

### 相关仓库

[Web 应用仓库](https://github.com/Danmaku-Anywhere/web)包含一个基于 Kazumi 规则的 Angular 看番网站和 `bangumi-api` 包。网站需要搭配浏览器扩展才能使用全部功能。

[后端仓库](https://github.com/Danmaku-Anywhere/backend)包含一个 Cloudflare Worker，负责与弹弹play API 交互、提供 AI 服务，以及代理弹幕源目录。

开发说明请参阅两个仓库各自的 README。
